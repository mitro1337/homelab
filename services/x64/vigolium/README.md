# Vigolium (guest 102)

Vigolium is recorded in the x64 inventory as an LXC service. The upstream project provides web and API scanning, AI-assisted workflows, source-code review, and report generation.

This repository does not track the guest definition or deployment manifest. Confirm the live guest settings before operating it. Use only against authorized targets and keep the guest isolated; upstream notes that agent mode is not sandboxed and extensions may run commands. Do not commit API keys or populated environment files.
